# Генератор Карточек Персонажей

Скрипт для автоматической генерации SVG-карточек персонажей на основе шаблона и текстовых данных. Проект создает 10 уникальных карточек, подставляя характеристики, навыки и стилизуя названия навыков специальными символами.

![Пример карточки](src/example.svg)
## Описание

При запуске `main.py` скрипт:
1. Загружает SVG-шаблон из `src/charsheet.svg`.
2. Читает список доступных навыков из `skills.txt`.
3. Использует маппинг символов из `letters_mapping.txt` для стилизации названий навыков.
4. Генерирует 10 карточек, заполняя следующие поля:
   - Имя, Профессия, Родной город
   - Характеристики: Сила, Ловкость, Выносливость, Интеллект, Удача
   - 3 случайных навыка (с заменой букв на стилизованные символы)
5. Сохраняет готовые SVG-файлы в папку `output/svg/`.

## Запуск

### Требования
- Python 3.12+

### Инструкция
Создайте виртуальное окружение:
```powershell
python -m venv .venv
```
Активируйте виртуальное окружение:
```powershell
.venv\Scripts\activate
```

Установите зависимости:
```powershell
pip install -r requirements.txt
```

Запустите скрипт:
```powershell
python main.py
```

После запуска скрипта появится папка `output/svg/` в ней будут лежать готовые карточки.
